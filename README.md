# Christmas list

A one-page gift list. Tapping "Got it" hides a gift for everyone who opens the link; "Show bought gifts" lets anyone put one back.

Deploy on Vercel: import this repo, then in the project's Storage tab create a Blob store and connect it to the project (that adds the BLOB_READ_WRITE_TOKEN setting the check-off needs). Redeploy once after connecting it.
